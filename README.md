# Have You Tried Turning It Off?

Entry for the make.fun competition "Have You Tried Turning It Off?"
(`u-motasimfuad-have-you-tried-turning-it-off-154a938b`).

`main.py` writes one funny line — a hopeless tech support agent speaking
to a desperate customer — to `/output/entry.txt`, then checks the sealed
gate locally: UTF-8 text, 1 to 199 characters, not only whitespace.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
